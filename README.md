# ذكرى للطباعة (Zekra for Printing)

المتجر الإلكتروني العراقي الرائد لخدمات الطباعة الحرارية، الحفر الليزري، وصناعة الهدايا التذكارية والمخصصة بالدينار العراقي (IQD).

## 🚀 المميزات الرئيسية
- **واجهة عربية حديثة وفاخرة** (Arabic-first RTL) مع خطوط Cairo و Tajawal.
- **تصفح وبحث المنتجات**: إطارات خشبية، أكواب سيراميك، مطارات حرارية، وشاحات تخرج، وتيشيرتات.
- **سلة مشتريات وتوصيل مرن**: خيارات تسعير توصيل ديناميكية (داخل بغداد / كافة المحافظات) يتحكم بها المشرف.
- **الدفع عند الاستلام (Cash on Delivery - COD)**.
- **فاتورة رقمية معتمدة**: توليد فواتير رسمية قابلة للطباعة والتحميل بصيغة PDF.
- **نظام تتبع مباشر للطلبات** عبر 10 مراحل زمنية.
- **محادثة مباشرة بين الزبون والمتجر** مع إمكانية إرفاق المنتجات.
- **لوحة تحكم إدارية شاملة (Admin Dashboard)**: إدارة المنتجات، الأقسام، الطلبات، البانر، الفيديوهات الترويجية، حسابات التواصل، وأسعار الشحن.
- **دعم تكامل Supabase**: مخطط SQL كامل وجاهز لإنشاء الجداول وصلاحيات الأمان RLS.

## 🛠️ التقنيات المستخدمة
- **React 19** + **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **Lucide Icons** & **Canvas Confetti**
- **Supabase Integration Ready**

